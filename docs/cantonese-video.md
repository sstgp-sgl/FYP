# 粤剧视频：从关键帧到彩色三维模型

打开网页的 **粤剧视频 · 镜头时间轴与演员重建** 入口（`/video`）。这是原视频的镜头和静态模型浏览工具，不会生成演员连续动作。

## 如何操作

1. 上传 WebM、MP4 或 MOV。默认最大 1GB、两小时、画面不超过1600万像素。保留原片，不要用屏幕截图代替提帧。
2. 选择原片起点、终点，以秒为单位，单次最多180秒。填写作者、来源和许可。
3. 点击“生成预览与镜头时间轴”。服务在后台生成 H.264 MP4 预览、检测镜头切换，再从每个镜头30%、50%、70%位置挑选较清晰的一帧。
4. 点击镜头或关键帧，播放器跳到相应位置。播放器下方同时显示原片时间和片段时间。推拉、身段变化不一定构成切镜头；单镜头也可以添加多张关键帧。
5. 播放或拖动到合适画面，点击“将当前时刻增加为关键帧”；也可以在一张卡片上选择“用当前时刻替换”、修改名称或删除。约一帧前后移动是按名义帧率估算，实际提取以视频可解码画面为准。
6. 在全身完整、遮挡较少的关键帧点击“选择演员 / 重建”。在嵌入的原图片流程中点击主体点，用排除点去掉背景，查看分割前景，确认头饰、靠旗、衣袖和衣摆。
7. 如需先看效果，点击“仅重建预览（不登记资产）”，无需确认名称。正式登记时输入并确认名称，使用 TripoSR。成功后回到该关键帧卡片打开彩色三维网格或下载 ZIP；处理期间自动更新状态，也可以点击刷新结果。

视频中的演员名称和剧情由使用者确认；系统不识别角色身份。代表帧清晰不保证全身完整，特写通常需要手动替换。新视频重建强制保留 TripoSR 预测 RGB，模型仍可能缺面、头饰变形或背面失真。

## 安装与执行

在已有 CPU 网页环境和 GPU 模型环境的基础上，增加视频工具：

```bash
python -m pip install -r requirements-video.txt
```

若已有 FFmpeg，可直接在 PATH 使用，或设置 `FYP_FFMPEG=/absolute/path/ffmpeg`，不依赖 ffprobe。SAM/TripoSR 的代码和权重仍按原重建说明准备。本地视频演示可配置 `"video_only": true`，禁用模型提交；GPU网页不设此选项。

查看素材总览（CPU）：

```bash
python scripts/video_project.py inspect \
  --video '/absolute/path/Chinese_opera,_cantonese_春花笑六郎.webm' \
  --out /absolute/path/video-inspect
```

向**尚未启动**的网页状态目录导入并处理一段视频，避免重复上传大文件：

```bash
python scripts/video_project.py import \
  --video /absolute/path/source.webm \
  --config /absolute/path/storyboard-web.local.json \
  --start 30 --end 210 \
  --attribution '作者、来源链接、许可及截取说明'
```

随后使用原 `scripts/serve_storyboard.py --config ...` 启动，打开 `/video`。HPC 的解码、视频处理和模型推理均在 Slurm 分配内执行，登录节点仅用于传输文件、编辑配置和提交作业。当前小型服务串行执行视频与模型任务；视频使用 CPU，SAM/TripoSR 使用 GPU。

## 保存、恢复与失败

项目位于配置 `root/videos/<project_id>/`，包括原片、预览、原始分辨率 PNG 和 `project.json`。项目记录原片哈希、原时间戳、检测阈值、关键帧和关联任务；模型 ZIP 的 `web-job.json` 保留帧及素材来源。

刷新后从项目历史继续。服务中断的处理任务会标记 interrupted，用新请求重试；已有完整关键帧的项目不重新分段，想改变范围应导入新项目。替换或删除关键帧会保存归档记录，旧模型不会显示在新帧上，仍可从原任务历史查看。多窗口修改遇到版本冲突时，刷新项目后重试。

第一版按画面切换分段，不能自动理解剧情。支持人工增删改帧，暂不支持编辑镜头边界、在线视频平台抓取、跨帧角色跟踪、动态模型或多帧几何融合。

## 测试

```bash
python -m pytest tests/storyboard/test_video.py -q
```

测试用真实 FFmpeg 生成红蓝镜头验证解码、分段和时间；模型执行器在这类接口测试中为显式替身，不能当作真实重建质量证据。
