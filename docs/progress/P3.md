## 坐标与冻结配置

世界右手 Y-up，世界 +X 为右，关系不随相机旋转改变。P3 要求源 scene.reference_frame.right 为 +X；不支持的旧参考方向显式拒绝。

- gap=0.2U；near_max=0.5U；far_min=1.5U；空间容差 epsilon=1e-4U。
- near/far 使用**地面 AABB 间最短距离**，不是中心距离；non_overlap 允许接触，相交面积容差为 epsilon²。
- keep_pose：平移/尺度容差 1e-6，旋转角容差 1e-5 rad。
- 默认 X/Z 平移搜索域均为 [-6,6]，max_evaluations=5000；请求可在合法范围内覆盖。
- 配置新增 `configs/storyboard.yaml:spatial`，实际由布局服务读取，再被请求 settings 覆盖。运行保存 config.json 和完整解析后的 spatial_request.json，使之后的独立验证不依赖变化的默认值。
- U 沿用源场景单位，本演示为 arbitrary 创作单位，不是物理米。

AABB 通过原边界的八个角变换计算，不只变换 min/max 两点；它是保守包围近似，不是精确物理碰撞。固定尺度和旋转也由独立检查验证，不通过改变资产大小伪造远近。

HPC 结果目录下的四个成功演示均通过持久化独立复验：

两个故意失败演示：

- **conflict**：同一对象相对同一锚点同时 left_of 和 right_of。返回 contradictory_constraints，proof=positive_left_right_cycle；不产生成功图片。独立 CLI 调用退出 1。
- **budget_exhausted**：将预算设为 1 次检查并要求远距离；返回 layout_not_found、budget_exhausted=true、proof=null，保留失败诊断，不宣称已证明无解。
