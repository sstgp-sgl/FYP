## 实现

- StoryPlan v1 / SceneIntent：恰好三幕，2–3 个已注册实例，引用与资产白名单严格校验；拒绝未知事件、重复 ID、非法继承和无效参数。保留旧 SceneDocument schema。旁白与事实引用分开保存，文本安全转义；不宣称对自由文本完成语义理解。
- 按幕继承：默认继承上一幕状态；仅修改明确指定的主体。静态关系复用 P3；approach / retreat 先转为候选布局的硬条件，再独立验证。hold 锁定完整姿态及可见性，appear / disappear 仅改变可见性。事件与实际时间上一幕比较，即使显式选择较早的继承基幕，也不能绕过事件检查。
- 距离定义：approach / retreat 使用地面 AABB **中心距离**，默认变化至少 0.2U；near / far 仍用地面 footprint 间最短距离。approach 不自动意味着 near。默认所有可见实例落地、互不穿插；尺度、旋转与资产引用不漂移。
- 相机：overview / focus，固定 960×640、45° FOV；overview 使用整部故事的范围保持共同相机，focus 只改变相机。检查实际投影八角边界的 5% 留白，以及 ID 缓冲中遮挡后剩余像素。每个实例平衡采样，总预算 120,000 点；默认正像素门槛为 1 像素且比例 >=1e-6，属于可配置开发初值，不代表感知质量评价。
- 导出：每幕 PNG、场景 JSON、镜头 JSON、完整 PLY/实例范围、ID/深度、旁白 txt；整部 HTML、原始输入快照、冻结资产、配置、代码及产物哈希、运行状态和独立复验报告。
- 失败保留：非法动作返回 unsupported_action；中途失败保存已有有效幕并标记 partial_failed，不生成三幕成功的替代结果。新运行要求新目录。
