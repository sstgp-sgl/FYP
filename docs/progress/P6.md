# P6：网页端到端集成

日期：2026-11-22。状态：完成 P6，未开始 P7。

## 完成的功能

新增独立网页入口 `web/storyboard/index.html`、FastAPI 服务 `src/storyboard/web.py`、持久化单 worker 队列 `src/storyboard/web_jobs.py` 与启动脚本 `scripts/serve_storyboard.py`，连接已有 P2–P5 模块。

网页支持两条入口：选择已有真实资产；或上传照片、点击正负提示点、查看 SAM2 分割、确认名称与掩码、选择重建方法并注册新资产。重建选择接入此前模块化的 VGGT、TripoSR、Hunyuan 三个后端。本阶段实际新上传链路使用 Hunyuan3D-2mini，其余两个后端沿用上一阶段的测试结果，本阶段没有再次执行它们的完整浏览器推理。

输入故事后执行真实 DeepSeek 调用、结构化故事编译、三幕静态渲染与独立验证。画面、旁白和状态随轮询出现；历史记录、刷新恢复与 ZIP 下载可用。P5 的超时机制使用主线程信号，因此从 worker 启动独立 CLI 子进程，凭据仅由环境继承。

每个任务冻结资产、初始场景与配置。UUID request_id 对相同输入去重，对冲突输入返回 409；提交期间锁定按钮。单进程锁防止双 worker，重启将未结束任务标为 interrupted，不悄悄重复推理。部分失败保留已生成画面。只允许登记产物的预览和下载，拒绝越界、符号链接及未登记文件；下载前校验 SHA256。页面文本通过 textContent/createTextNode 显示。
