## 本阶段做了什么

新增 `src/storyboard/edits.py`：严格类型的 EditPatch，包含 base_version、有限操作和锁定幕。只允许修改已有关系（left_of/right_of/near/far）、距离、overview/focus 或指定幕旁白，不开放事件、任意代码或矩阵修改。语言模式只调用模型一次，保留原始响应与 schema；不做正则兜底或静默回退。

`EditStore` 使用进程锁和原子版本指针。任务基于过期版本时拒绝覆盖；失败提案保留为独立记录，有效旧版和历史版本继续可用。原版本以不可变文件复用；所有写入先解除硬链接或原子替换，点云不重新重建。

只编译被修改的布局，只有姿态或镜头实际变化时才重渲染对应幕。仅旁白修改不重建、不渲染；仅镜头修改不移动物体。每次仍重新验证整部故事的几何、继承、跨幕事件、导出及可见性，防止第二幕的改动破坏第三幕事件。

网页新增指定幕编辑、语言请求、默认锁定、显式解锁、版本切换、差异与验证详情。语言 API 要求明确锁定范围，模型不得自行修改 base_version 或锁定列表。取消锁定本身不会自动修改其他幕，必须明确指定它的修改。若事件本身需要放宽，例如本幕 hold 与移动要求矛盾，应返回原故事修改事件并重新生成，首版不直接编辑事件。
