先导使用人物/熊五任务，各方法一次，共 15 次。根据先导时间和用量，冻结主比较 54 次：人物/鸭 T1、T2、T4，熊/鸭 T3、T4、T5，各三方法、三次重复。两个组均包含 focus，全部五类任务均覆盖；任务分配在主比较产生结果前冻结。

另做 12 次预算敏感性对照，以及 18 次已保存响应的机制消融重放。全部失败保留在分母，不按隐藏用户评分挑选模型候选。先按组内任务汇总重复，再汇总资产组，不将三幕当作三个独立样本。

## 方法与公平条件

- B0：直接输出各幕绝对坐标和可见性，不用布局器修正语义。主比较一次调用。
- B1：输出静态关系、显式可见性及镜头，events 为空；保留普通继承与 keep_pose，不使用 approach/retreat/hold 事件求解。主比较一次调用。
- Ours：关系、事件、状态与执行检查，最多三次调用，反馈仅包含执行错误，不包含隐藏评分答案。

共享资产名称/ID/几何边界、初态、距离与单位定义、640×480 镜头与渲染器、15–60 字旁白硬格式、模型与生成参数。所有方法最终都按冻结用户要求评分，不以自己输出的 constraints 或 fact_claims 为答案。

模型为 `deepseek-v4-pro`，temperature 0、thinking disabled、JSON object、最大输出 3072。保存 API 响应、usage、请求/响应标识、fingerprint 与全部尝试。云端权重不能完全固定，API 不支持此处的 seed；不能仅凭相同模型名声称严格确定性。

## 主比较结果

以下“全部满足”指预定空间、时序、镜头、引用绑定及产物条件全部通过，不包括完整旁白语义与重建形状质量。

- **B0：8/18，44.4%**。空间要求 44.4%，事件要求 91.7%；18 次调用，52,464 reported tokens，中位总耗时 80.3 秒。
- **B1：13/18，72.2%**。空间要求 88.9%，事件要求 79.2%；18 次调用，84,646 reported tokens，中位总耗时 117.0 秒。
- **Ours：18/18，100%**。空间与事件要求均 100%；18 次调用，85,123 reported tokens，中位总耗时 138.8 秒。

原始响应中的可读引用合法率均为 100%，覆盖各 18 次运行；它检查 ID 合法性，不是完整自然语言指代理解准确率。按用户预定对象检查的目标可见率为 B0 94.4%、B1 88.9%、Ours 100%。缺失/失败输出保留为未满足。

观测到的锁定字段变化率均为零，但 B0/B1 的覆盖率分别为 94.4%/88.9%，Ours 为 100%；不能把缺失输出说成“已证明保持不变”。旁白事实支持率保持未评，需要完整读图与阅读文本。

B0 的十项失败为九项用户要求未完整满足、一项旁白长度格式失败；B1 五项失败为三项要求未完整满足、两项旁白长度失败；Ours 本轮无结构化失败。常见例子是坐标仍保留初始 0.8U 间隔而未达到 near≤0.5U，或只满足 far 却没有发生要求的靠近。

## 预算对照与消融

允许相同的最多三次调用上限后，B0 为 **3/6，50%**，实际六次调用；B1 为 **3/6，50%**，实际十次调用。两种基线合计 16 次调用、74,997 reported tokens。每组合仅一次，不与主比较的三次重复形成同等精度，不能将批次差异直接解释为预算的因果影响。

Ours 主比较 18 次全部首次调用被接受，没有实际使用反馈修正。因此本轮的主方法较高通过率不能归功于更多调用，也不能证明反馈修正有贡献。

消融均使用对应主比较 r0 的已保存响应：

- 去掉反馈修正：**6/6，100%**。因为源响应已经首次通过，本轮未检验到反馈修正的必要性。
- 去掉状态继承：**3/6，50%**。恢复初态会破坏部分保持或跨幕移动要求。
- 固定 overview 镜头：**4/6，66.7%**。两项明确要求 focus 的任务失败。

18 次消融的 provider mode 均为 replay，新 API 调用与 token 用量均为零；它们不是 18 个新独立模型样本。预算和主比较在不同时间段执行，总耗时含 API 等待及 CPU 处理，不能把批次速度差异全归因于算法。

主比较加预算对照共 **70 次 API 调用、297,230 reported tokens**。该数字不包含先导、早期调试和新资产 GPU 重建；没有已验证账单价格，不编造货币费用。
